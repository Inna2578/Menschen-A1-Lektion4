# WortWerk · Lernwortschatz 4

Простая PWA-тренировка 46 немецких слов и выражений из Lernwortschatz 4. В приложении только два задания:

- **Карточки** — четыре темы: мебель, описание, деньги, другие слова. Нажмите на карточку, чтобы перевернуть, используйте стрелки для перехода и кнопку с динамиком для произношения немецкого слова. Направление перевода можно изменить.
- **Тест** — 10 случайных слов, к каждому по четыре варианта русского перевода. В конце показан результат.

Никаких регистраций, рекламы, внешних библиотек и сетевых запросов. Приложение работает без интернета после первого открытия (PWA с сервис-воркером). Озвучивание использует голоса, установленные на устройстве; наличие немецкого голоса зависит от системы.

## Как опубликовать на GitHub Pages

1. Распакуйте ZIP-архив. Загрузите **содержимое** папки `deutsch_l4_pwa` в корень репозитория GitHub (файлы `index.html`, `app.js`, `styles.css`, `service-worker.js`, `manifest.webmanifest` и папку `icons`).
2. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**. Укажите ветку `main`, папку `/ (root)`, сохраните.
3. Откройте адрес, предоставленный GitHub Pages, на iPhone в Safari. Нажмите **Поделиться → На экран «Домой»**.

Если вы заменяете предыдущую версию, загрузите новые файлы поверх старых, сохранив имена файлов. Новая версия сервиса офлайн-кэша автоматически заменит старую при следующем посещении опубликованного сайта онлайн.

## Структура

- `index.html` — интерфейс с главным меню
- `styles.css` — простое оформление для телефона
- `app.js` — слова, карточки, тест
- `service-worker.js` — офлайн-кэш
- `manifest.webmanifest` и `icons/` — установка PWA
